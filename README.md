# SneakerStore E-commerce Mini Engine

Landing page estática para una tienda de sneakers con un estilo premium, elegante y moderno. El proyecto está desarrollado con HTML, CSS y JavaScript puro, sin dependencias externas, con enfoque en una experiencia visual moderna para marcas como Nike, Jordan y Louis Vuitton.

## Descripción del proyecto

Este proyecto simula la interfaz de una tienda de calzado premium, con:

- Hero section con slogan y CTA principal
- Navegación moderna y responsive
- Sección de marcas destacadas
- Diseño dark luxury con paleta premium
- Footer con información de la marca y enlaces de navegación
- Estructura preparada para ampliarse con catálogo, filtros, carrito o ecommerce completo

## Características

- Diseño responsive para desktop y dispositivos móviles
- Estilo visual premium basado en colores oscuros y acentos violetas
- Uso de imágenes optimizadas con fondo de alta calidad
- Estructura modular y fácil de mantener
- Código limpio y compatible con navegadores modernos

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript (sin frameworks)
- Assets gráficos locales

## Requisitos

- Un navegador web moderno
- Un servidor local opcional para servir la página (recomendado para mejores prácticas)

## Instalación y ejecución

1. Clona o descarga este repositorio.
2. Navega a la carpeta del proyecto.
3. Abre `page/index.html` directamente en el navegador, o bien ejecuta un servidor local:

```bash
cd SneakerStore-E-commerce-Mini-Engine
python -m http.server 8000
```

Luego abre en tu navegador:

```text
http://localhost:8000/page/
```

## Uso

La página se puede usar como base para una landing page de una marca de sneakers o como punto de partida para un e-commerce más completo. Si deseas extenderla, puedes añadir:

- catálogo de productos
- carrito de compras
- filtros por marca y precio
- formulario de contacto
- sección de testimonios
- checkout simulado
